# Experiment 4

**Aim:** Develop a program to control a DC motor with an Arduino board.

## Program

```cpp
void setup() {
  pinMode(11, OUTPUT);
}

void loop() {
  digitalWrite(11, HIGH);
  delay(2000);
  digitalWrite(11, LOW);
  delay(2000);
}
```
