# Experiment 8

**Aim:** Develop a program to detect the gas leakage in the surrounding environment.

## Program

```cpp
int Smoke_Sensor = 0;

void setup()
{
  pinMode(A0, INPUT);
  Serial.begin(9600);
  pinMode(5, OUTPUT);
  pinMode(7, OUTPUT);
}

void loop()
{
  Smoke_Sensor = analogRead(A0);
  Serial.println(Smoke_Sensor);
  if (Smoke_Sensor >= 60) {
    digitalWrite(5, HIGH);
  } else {
    digitalWrite(5, LOW);
  }
  if (Smoke_Sensor >= 65) {
    digitalWrite(7, HIGH);
  } else {
    digitalWrite(7, LOW);
  }
  delay(10);
}
```
